# 26 · 致谢与许可
English: `docs/26-致谢与许可.en.md`


> 这一页回答三件事：你能拿这个包做什么（许可）、我们用了谁的劳动（致谢）、什么不随包分发（第三方边界）。

## 一、许可（一句话版）

All Rights Reserved · Beta

| 你想做的事 | 可以吗 |
|---|---|
| 自己玩、装在存档/服务器里用 | ✅ 可以 |
| 原样转发 zip（不修改，附上本仓库链接与 LICENSE） | ✅ 可以 |
| 二创：改规则、改描述、做整合包/视频/直播 | ✅ 改规则本来就支持；发布时请注明来源（见下） |
| 二次发布修改过的包（改内容后重新分发） | ⚠️ 请先取得许可 |
| 商用（收费服务器、付费整合包、付费下载） | ⚠️ 请先取得许可 |
| 把本包当作自己的作品署名发布 | ❌ 不行 |

全文以仓库根的 [LICENSE](../LICENSE) 为准（本页只是人话摘要，不构成额外授权）。取得许可的方式：在 [Issues](https://github.com/Doom-Flare/doom.nats/issues/new/choose) 里开一条，写清用途、范围、是否收费。

## 二、第三方边界（重要）

| 项 | 状态 |
|---|---|
| Minecraft / Mojang 的资产（贴图、模型、音效、代码、反编译产物） | 不含；本仓库与 zip 里都没有 |
| 第三方外观 / 模型包（rig 之类） | 不随包分发。自定义外观桥接只是 `rules/rigs.json` 这个机制（源码在 `src/tools/gen_exp_aj.mjs`，未随 v4.25/v4.28/v4.30.0 成品发布）：桥接只演示机制，示例里用的是 `your_rig` 这种占位 id；真实 rig 由你自己提供并遵守它自己的许可 |
| 本包生成的内容 | 只有数据包本体（`pack.mcmeta` + `data/` 下的函数、标签、谓词） |
| 版本与兼容 | 见 [25-兼容与版本](25-兼容与版本.md)；实验性变体会借用一个原生实验性旗标 |

> 一句话："能不能挂外观"是机制，"外观从哪来"是你自己的事。我们不搬运、不分发第三方的模型/贴图包。

## 三、致谢

### 平台与参照

- Minecraft: Java Edition（Mojang Studios）：本包是非官方作品，与 Mojang / Microsoft 无关联、未获其背书。复刻的目标是 1.21.6 的原版行为本身。
- 原版机制本身：逐实体规则、容量曲线、消失层、`finalizeSpawn` 组数据等，全部以 1.21.6 实际运行为准（对照表见 [`17-逐实体刷怪规则核对.md`](17-逐实体刷怪规则核对.md)）。

### 工具与社区

| 用了什么 | 用途 |
|---|---|
| [Spyglass](https://github.com/SpyglassMC/Spyglass)（作者与社区） | 构建期的数据包静态检查思路（可选接入） |
| [misode 的数据包生成器](https://misode.github.io/) | 生成标签/谓词等 JSON 时的参考实现 |
| [PackSquash](https://github.com/ComunidadAylas/PackSquash) | 发布前压缩/校验数据包的参考工具 |
| Minecraft 数据包社区（wiki 与 Discord 上的惯例文档） | 命名、标签、加载顺序等约定 |
| 每一位在测试存档里帮忙验证的玩家 | 真机验收里那些"抓得到、复现得了"的 bug |

### 我们自己造的

生成器与静态门就在本仓库 `src/`；真机测试台与逐轮报告是作者本机的东西，不随本仓库分发；本仓库只放玩家要的东西（见 README 的"仓库结构"）。

## 四、怎么署名 / 怎么引用

转发或做视频时，写上这两样就够：

```
doom.nats — 原版自然生成复刻（数据包）· v4.31.0
https://github.com/Doom-Flare/doom.nats
```

- 只想先看看怎么用：先读 [快速上手](wiki/快速上手-在游戏里改规则.md) 与 [示例库](wiki/示例库.md)

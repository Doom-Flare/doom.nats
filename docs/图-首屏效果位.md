# 首屏效果图位（占位说明）
English: `docs/图-首屏效果位.en.md`

README 的第一屏留了一个图片位，目标：让人 3 秒内看到"这包在游戏里长什么样"。现在还是空的（源码里是注释，不会显示破图）。

## 一、图放哪、怎么接上

| 项 | 约定 |
|---|---|
| 文件路径 | `docs/assets/首屏效果.png`（仓库里建这个目录） |
| 尺寸 | 宽 1600 px 左右，横构图；README 里按 720 px 宽显示 |
| 大小 | ≤ 500 KB（PNG 可以先过一遍压缩；GIF 首推 ≤ 3 MB） |
| 接上 | 打开 `README.md`，把这一行前面的 `<!--` 和结尾的 `-->` 去掉：`<p align="center"><img src="docs/assets/首屏效果.png" width="720" alt="doom.nats 在存档里跑起来的样子"></p>` |

## 二、拍什么（按优先级挑一张）

1. 一眼能看出"原版刷怪回来了"：夜里的地表，一堆僵尸/苦力怕从暗处走出来。视角略高，能看到地形与生物群。
2. 能看出现场感：第一人称站在洞口/树林边，聊天栏带一句就绪提示（可选，但很加分）。
3. 如果有动态图：同机位的 5 秒 GIF（生物从无到有出现），比静图更能说明问题。

拍之前建议先跑一遍（都能在游戏里直接敲）：

```
/function doom.nats:mode/survival      # 接管刷怪（默认行为）
/time set midnight                     # 夜里更直观
/gamerule doDaylightCycle false        # 定住时间，方便多拍几张
/function doom.nats:debug/env          # 顺手确认包在工作
/function doom.nats:debug/reject_report   # 想解释"为什么不刷"时用这张图
```

## 三、别放什么

- 别放带无关 HUD 信息的截图（坐标、F3 调试屏、其它插件的聊天刷屏）。
- 别放第三方外观/模型包的截图，我们不随包分发那些内容（见 [26-致谢与许可](26-致谢与许可.md)）；要展示就自己拍自己的 rig，并注明来源。
- 别放没跑起来的界面（比如只有命令回显、场上一只生物都没有的图）。

## 四、拍完之后

1. 存成 `docs/assets/首屏效果.png`，在 README 里取消注释（见第一节）。
2. 顺手在 [CHANGELOG](../CHANGELOG.md) 记一行"README 首屏加效果图"。
3. 如果这张图想同时用在 Wiki 的 Home 页：`docs/wiki/Home.md` 里也加同一张图（Wiki 推送脚本会带上 `docs/wiki/` 的改动）。

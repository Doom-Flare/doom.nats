## 1. Where the Image Goes and How to Wire It Up

| Item | Convention |
|---|---|
| File path | `docs/assets/首屏效果.png` (create this directory in the repo) |

| Wiring it up | Open `README.md` and remove the leading `<!--` and the trailing `-->` from this line: `<p align="center"><img src="docs/assets/首屏效果.png" width="720" alt="doom.nats 在存档里跑起来的样子"></p>` |

## 2. What to Shoot (Pick One, in Priority Order)

1. Immediately communicates "vanilla spawning is back": a nighttime surface scene with a crowd of zombies/creepers walking out of the dark. Camera slightly high, so the terrain and the group of mobs are both visible.
2. Conveys the moment: first-person, standing at a cave mouth or the edge of a forest, with a ready message in the chat (optional, but a big plus).
3. If you can do motion: a 5-second GIF from the same camera angle (mobs appearing from nothing) explains it better than a still.

Before shooting, it helps to run through this once (all can be typed directly in game):

```
/function doom.nats:mode/survival      # Take over spawning (default behavior)
/time set midnight                     # More obvious at night
/gamerule doDaylightCycle false        # Freeze time so you can take several shots
/function doom.nats:debug/env          # Quickly confirm the pack is working
/function doom.nats:debug/reject_report   # Use this one when you want to explain "why nothing spawns"
```

## 3. What Not to Include

- No screenshots with unrelated HUD information (coordinates, the F3 debug screen, chat spam from other plugins).
- No screenshots of third-party appearance/model packs; we do not distribute that content (see [26-Credits and License](26-致谢与许可.md)); if you want to show one, shoot your own rig and credit the source.
- No shots of a scene that isn't actually running (for example, only command echoes, or not a single mob on the field).

## 4. After Shooting

1. Save it as `docs/assets/首屏效果.png` and uncomment the line in the README (see section 1).
2. Add a line to the [CHANGELOG](../CHANGELOG.md) such as "add hero image to the README first screen".
3. If you want the same image on the Wiki Home page too: add it to `docs/wiki/Home.md` as well (the Wiki push script carries changes under `docs/wiki/`).

## 一、前置：关闭原版自然生成

本包的全部生成都走 `/summon`，原版 cap 和 mobcap 都管不到 `/summon`（wiki 已证实），所以两者不冲突：

```
/gamerule doMobSpawning false
```

- 这会停掉原版的自然刷怪。本包生成、刷怪笼、生成蛋都不受影响。
- ⚠️ 需实测确认：区块生成期生成被动生物（`spawnMobsForChunkGeneration`）是不是也归这条规则管，本包未做假设。
- ⚠️ 单人开着暂停菜单不刷怪（`tickPaused()`）；专用服务器 `pause-when-empty-seconds` 默认 60 秒后停 tick。

## 二、验证（一条命令）

```
/reload
/function doom.nats:debug/all
```

它依次跑五项：环境探针 → 注册表清单 → dryrun 诊断 → 归因直方图 → 消失报告。
随后在包外执行 `node doom.nats/tools/collect.mjs`，报告里会出现「生成失败归因直方图」与「环境快照」两节。

### 归因码表（`$chk.reason`）

| 码 | 含义 | 常见修法 |
|---|---|---|
| 0 | 抽不到合格区块（周围 17×17 未加载） | 看 `debug/env` 的 `chunks`；靠近已加载区域 |
| 1 | 24 格球内有玩家（原版 `distSq <= 576`） | 正常行为，走远一点 |
| 2 | 出 128 格（`despawnDistance²`） | 正常行为 |
| 3 | 光照档不足 | 调 `$eff.light` 或看情形的 `lightRule` |
| 4 | 落位方块不允许 | 最可能需要改的地方：扩充 `#doom.nats:standable` / `#doom.nats:spawnable_at` |
| 5 | 全局容量已满 | 调 `$eff.max_<类别>` 或提 `doom.nats` 节拍 |
| 6 | 附近玩家本地容量全满 | 同上；或让玩家分散 |

`dryrun` 会把落位拆成 `$dr.at` / `$dr.above` / `$dr.below` 三个分数，直接指出是哪一处不过。

⚠ 实测里 `0`（抽不到合格区块）与 `8`（选不到物种）严格同步自增（5 秒粒度逐点相等）。所以这两个数的相对大小分不出原因，直方图分不清这两类。`$rej.8` / `$rej.9` 只 `add` 不 `set` ⇒ 从不归零（世界生命期累计）。见 [[FAQ]]。

## 三、参数总表（全部是计分板虚位玩家，objective = `doom.nats`）

| 参数 | 默认 | 含义 |
|---|---|---|
| `$snap_period` | 20 | 快照节拍：环境/情形/容量/群系刷新的间隔。⚠ 验收脚本会把它设成 `20000`（“冻结快照”）来隔离变量；**世界若留在冻结状态，表现就是“完全不刷怪”**（`$snap.chunks=0` ⇒ `$cap.monster=0` ⇒ 每次尝试 `reason=5`），而 tick 与装载日志全正常。排查见 [[FAQ]] |
| `$chunks_mode` | 0 | `spawnableChunkCount` 近似：0=只扫首个玩家（单人精确/多人低估）、1=逐玩家累加（多人高估） |
| `$eff.period` | 5 | 刷怪节拍（每 N tick 一次 `spawn/try`） |
| `$eff.max_monster` / `_creature` / `_ambient` | 70 / 10 / 15 | 各类别 `maxInstancesPerChunk` |
| `$eff.light` | 7 | 光照档上限（档位 0/3/7/11/15） |
| `$despawn_period` | 20 | 消失检查节拍 |
| `$despawn_dice` | 40 | 消失掷骰分母（等效原版每 tick 1/800） |
| `$despawn_log` | 未设 | 设为 1 时打印每次概率消失 |

## 四、扩展点

### 1) 注册新的环境情形

改 `tools/lib/circ-defs.mjs` 的 `CIRC` 表，然后重跑：

```bash
node tools/gen_pack.mjs && node tools/gen_effects.mjs
node tools/lint_pack.mjs && node tools/install.mjs --variant std
```

条目结构（`when` 与 `effects` 都是覆盖原版语义的参数，不是额外开关）：

```js
{ id: 'snow_night', when: { weather: 1, time: 'night', dim: 0 },
  effects: { period: 4, max_monster: 80, lightRule: 11 }, note: '雪夜' }
```

可用的 `when` 维度：`weather`(0晴/1雨/2雷暴) · `time`('night') · `dim`(0/1/2) · `players`(≥N) · `phase`(月相 0..7)。
`effects` 可覆盖：`period` · `max_<类别>` · `lightRule`。后注册者优先（顺序即优先级）。

### 2) 扩充落位方块（最常用）

编辑两个方块标签（按你地图的实际地形）：

- `data/doom.nats/tags/block/standable.json`：下方必须可站立（对齐 `on_ground` 的"1"判断）；
- `data/doom.nats/tags/block/spawnable_at.json`：此处与上方必须是可生成空位（对齐 `isValidEmptySpawnBlock` 的“非完整碰撞盒”意图）。

两者都能嵌套引用原版标签（如 `#minecraft:dirt`），也可以直接列方块 id。

### 3) 改群系刷怪表

数据来自 `_work/generated/biomes.json`（从 vanilla jar 导出）。
要改权重/增删物种，编辑该文件后重跑：

```bash
node tools/export_rosters.mjs && node tools/gen_mobs.mjs
```

> 导出保持原始权重和（不做归一化），区间划分与 vanilla `WeightedRandom` 逐点等价。

### 4) 让某生物免疫消失

给它加 `doom.nats.persistent` 标签（对应原版 `PersistenceRequired`）：

```
/tag <实体> add doom.nats.persistent
```

本包生成的实体默认带 `doom.nats.spawned` 与 `doom.nats.cat.<类别>` 两个标签。

## 六、一次完整实测的动作清单（v4.1）

五项检查见「二、验证」。一次能用来定标的测量按这个顺序做：

```
/reload                              # 新装的包会被重扫（不必退出重进世界）
/gamerule doMobSpawning false        # 关掉原版自然生成，本包接管
/time set night                      # 白天地表亮度高，怪物档过不去
# 站定约 2 分钟（别开暂停菜单、别让窗口失焦——单人暂停会停 tick）
/function doom.nats:debug/all
```

归因直方图先打数值再清零，所以每次调用就是一段独立测量窗口：

```
[nats.reject] rej: 0=<抽不到区块> 1=<24格有人> 2=<出128格> 3=<光照档> 4=<落位方块>
                    5=<全局容量> 6=<本地容量> 7=<spawn cost> spawned=<成功数>
[nats.light]  tier: 0=? 3=? 7=? 11=? 15=?      ← 光照失败时命中的档位
```

包外跑 `node doom.nats/tools/collect.mjs` 出报告。若 `_work/watch_collect.mjs` 在后台跑着，
它会自己抓到快照行后跑 collect，报告路径写进 `_work/collect.done`。

## 七、已知边界（不假装等同原版）

| 项 | 原因 | 现状 |
|---|---|---|
| 光照 | 谓词读不到亮度数值，也做不了“采样比较” | 用 5 档区间近似；原版是 `uniform(0..7)` 的概率通过 |
| 消失 | 读不到 `noActionTime` | 无法复刻“离开 32 格满 600 tick 才开始掷骰”，消失略快；掷骰分母已按节拍放大以保持单位时间期望 |
| 并集计数 | 欧氏 `distance` 表达不了 Chebyshev 方形 | 两模式近似（单人精确），精确并集需绝对坐标盒式判定（289 宏/快照） |
| `spawn_costs` | 需要连续能量场 | 未实现（原版仅 `warped_forest` 与 `soul_sand_valley` 非空） |
| `finalizeSpawn` 族群数据 | 逐生物逻辑 | 未实现（如僵尸骑鸡、羊的颜色继承） |
| 碰撞检测 | 实体 AABB | 用方块标签近似 |

# 21 · 玩家/地图作者可改清单（及改法）
English: `docs/21-玩家可改清单.en.md`

> "玩家"在本包里 = 用这份包做自定义地图的作者。下面每一项都给具体改法；改完统一 `/function doom.nats:cfg/apply`（或换维度后 `/function doom.nats:cfg/apply_here`）。
> 类型声明见 zip 解压后包内的 `doom.nats/mcdoc/doom.nats/config.mcdoc`（给编辑器提示用）。

## A. 配置（唯一入口：`doom.nats:config` → `cfg/apply` → `$cfg.*`）

```mcfunction
# 只写要改的键，其余取默认（cfg/setup 每次装载重写默认值）
data merge storage doom.nats:config {difficulty:3, special:100, batch:60, band:{mode:3,yMin:40,yMax:120}}
function doom.nats:cfg/apply
```

| 键 | 默认 | 改它会发生什么 |
| --- | --- | --- |
| `seaLevel.{overworld,the_nether,the_end}` | 63 / 32 / 0 | 水面窗口、发光鱿鱼 `y≤sea-33`、海龟 `y<sea+4` |
| `light.{...}` | 7 | 怪物"暗"档上限（`uniform(0..light)` 的近似档） |
| `cap.{monster,creature,ambient,water_creature,water_ambient,underground_water_creature,axolotls}` | 70/10/15/5/20/5/5 | 该类别 mobcap（`maxInstancesPerChunk`） |
| `distance.{...}` | 128（`water_ambient` 64） | 该类别的消失距离 |
| `noDespawnDistance` | 32 | 近于此距离清零 `noActionTime` |
| `playerExclusion` | 24 | 玩家 24 格内不刷（原版 `isRightDistanceToPlayerAndSpawnPoint`） |
| `spawn24` + `spawnX` `spawnY` `spawnZ` | 0（关）+ 0/0/0 | 世界出生点 24 格内不刷（v4.17）。默认关闭：数据包读不到 `getSharedSpawnPos()`，需作者声明坐标；`spawn24:1` 加三轴都给出才生效，缺一轴自动回到关闭。失败归因 `reason=10`（详见 docs/18 §2.2b） |
| `period` / `batch` / `maxBatch` / `density` | 5 / 6 / 40 / 0 | 刷怪节拍与吞吐；`density>0` 时 AIMD 自动调 `batch` |
| `dice` | 0 | >0 打开本包的概率消失层（原版 `checkDespawn` 之外的自选强度） |
| `creatureGate` | 400 | 被动生物进候选的节拍（原版 `gameTime % 400`） |
| `persist` | 0 | 1 ⇒ 生成物都带 `PersistenceRequired:1b`（永不消失） |
| `peaceful` | 0 | 1 ⇒ monster 整类不刷（数据包读不到难度，需作者声明） |
| `difficulty` | 2 | 0..3；只影响"蜘蛛在困难难度共享效果"这条组数据 |
| `special` | -1 | 区域难度 percent；-1 = 按 `difficulty` 自动（普通 75 / 困难 100） |
| `band.mode` | 0 | 0 自动找地面 / 1 固定带 / 2 跟随玩家±jitter / 3 均匀随机带（最接近原版） |
| `band.yMin` `band.yMax` `band.jitter` | 60 / 70 / 3 | 上面各模式的参数（`min==max` 有退化保护） |

## B. 方块标签（决定"哪里算能站/能生成空位"）

| 文件 | 语义 | 改法 |
| --- | --- | --- |
| `data/doom.nats/tags/block/standable.json` | 近似 `ON_GROUND` 的 `isValidSpawn`（顶面完整 ∧ 自发光<14） | 地图包覆盖同名标签；或跑 `node src/tools/propose_tags.mjs` 得到建议集 |
| `data/doom.nats/tags/block/spawnable_at.json` | 近似 `isValidEmptySpawnBlock`（非完整碰撞/非红石源/非流体/非危险方块） | 同上 |
| `data/doom.nats/tags/entity_type/<类别>.json` | 类别→实体（cap 计数与 `@e[type=#…]` 用） | 加自定义生物时补进来 |

## C. 可直接调用的函数（作者手里的开关）

| 函数 | 作用 |
| --- | --- |
| `doom.nats:cfg/setup` | 重写默认值（装载时自动跑一次） |
| `doom.nats:cfg/apply` / `cfg/apply_here` | 把 storage 折算成 `$cfg.*`；后者先探测当前维度 |
| `doom.nats:mode/auto` / `mode/off` / `mode/manual` | 生/关/手动接管（auto 会 `gamerule doMobSpawning false`） |
| `doom.nats:spawn/try` | 手动跑一次完整尝试（3 组、每组一次物种抽取） |
| `doom.nats:debug/env` / `debug/all` / `debug/clear` | 环境快照 / 全诊断 / 清场（跳过持久与骑乘） |
| `doom.nats:grp/init` + `grp/mem/<slug>` | 组数据层（内部用；测试与调试可直调，需 `with storage doom.nats:sel` / `doom.nats:grp`） |

## D. 存档/世界侧

| 项目 | 改法 |
| --- | --- |
| 原版刷怪 | `mode/auto` 会设 `gamerule doMobSpawning false`（本包自己接管）；想共存就 `mode/manual` |
| 游戏难度 | 只能由地图/服务端设置；本包用 `difficulty` 声明（读不到真实难度） |
| 世界出生点 24 格排除 | 已实现（v4.17，默认关闭）：数据包读不到 `getSharedSpawnPos()`，改法是在 `doom.nats:config` 里写 `{spawn24:1, spawnX:…, spawnY:…, spawnZ:…}` 再 `cfg/apply`（见 docs/18 §2.2b） |
| 地图自带 worldgen（覆盖 biome `spawners`） | 已实现（v4.18/Q7）：`node tools/apply_worldgen.mjs --worldgen <含 data/ 的地图目录>` → `export_rosters` → 9 个生成器；`--reset` 还原，`--status` 看当前状态。整套回归验证用 `node tools/regress.mjs --worldgen <目录>`（跑完自动还原并回读校验）。真机四相位数字见 `reports/验证-世界生成覆盖-20260928.md`（不在本仓库） |

## E. 不能改的（要改就得动生成器/代码）

| 项 | 为什么 |
| --- | --- |
| 群系→物种表（roster） | 由 `_work/generated/biome-rosters.json` 生成；改法是改提取器/生成器后重生成 |
| 逐实体规则（落位/光照/掷币/簇上限） | `tools/lib/entity-rules.mjs` 是唯一来源，产物禁止手改 |
| 结构 `spawn_overrides` | 目前只有下界要塞；其余结构见 docs/19 Q2（未实现） |
| Brain 记忆 / 学校鱼 leader / 狐狸目标列表 | 记忆项可以用 NBT 写（已实测 `dig_cooldown`），但传感器记忆每 tick 重算、对象引用与 Goal 列表不是数据 |
| 万圣节南瓜 | 读系统日历，数据包无接口 |

## F. 包体与测试基建

| 项 | 说明 |
| --- | --- |
| 安装 | 解压 `dist/doom.nats-v4.30.0.zip`，把 `doom.nats/` 放进 `<存档>/datapacks/`（脚本 `src/tools/install.mjs`） |
| 正式地图 | 不要带 `zz-test-fixtures` 与 `doom.log`（那是测试基建；install 会一并装，发布时删掉即可） |
| 校验 | `node src/tools/check_static.mjs`（生成器漂移/lint/闭包）；真机 `regress.mjs --reuse` |
